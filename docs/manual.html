지역 여행 수첩 제작 매뉴얼

강원 여행 수첩을 처음부터 만든 과정, 신청한 사이트, 설치·업데이트 방법을 정리했습니다. 다른 지역 관광 지도를 만들 때 이 순서대로 따라 하면 됩니다.

2026년 11월 13일 기준 · 저장소 flyaranaby-collab/gangwon-travel

1. 전체 구조

하나의 수첩 파일을 세 곳(웹 수첩, 안드로이드 앱, 홈페이지)에 함께 씁니다. 장소·날씨·열차 같은 자료는 GitHub가 정해진 시간에 공공 API에서 받아 저장소에 올리고, 앱은 켤 때마다 그 자료를 새로 읽습니다.

2. 만든 순서

실제로 만든 순서입니다. 다른 지역도 이 순서가 무리가 없습니다.

  1. 웹 수첩 시작: Claude 대화에서 지역·장소·코스·준비물을 담은 한 페이지 수첩을 아티팩트로 만들었습니다.
  2. 장소 직접 정리: 강릉·속초 등 대표 장소를 직접 조사해 이름, 좌표, 운영 시간, 팁, 태그를 넣었습니다(현재 약 250곳).
  3. GitHub 저장소와 앱: 저장소를 만들고, 수첩을 그대로 띄우는 안드로이드 앱(WebView)을 붙였습니다. 저장소에 올리면 APK가 자동으로 만들어집니다.
  4. 관광공사 자료 연결: 공공데이터포털 키로 관광공사 장소·숙소를 받아 1,200여 곳을 더했습니다.
  5. 사진: 위키백과(자유 이용) → 관광공사 → 관광사진(포토코리아) → 구글 지도 순서로 빈 사진을 채웁니다.
  6. 다국어: 한국어·영어·중국어·일본어 번역 사전을 따로 두고 빌드합니다.
  7. 운영 페이지: 장소 추가·수정·사진 등록을 앱 안에서 하고, 저장하면 저장소의 owner.json에 반영됩니다.
  8. 생활 정보: 날씨(노르웨이 기상청), 야간 병원·약국·응급실(국립중앙의료원), 캘린더 내보내기를 넣었습니다.
  9. 홈페이지: GitHub Pages로 고정 주소를 만들고 장소마다 검색용 페이지를 자동 생성했습니다.
  10. 분류 확장: 산·계곡·호수·강·숲·꽃·고원 분류, 사진 명소·여름 피서·리뷰 많은 곳 필터를 넣었습니다.
  11. 구글 지도 인기 장소: 지역×검색어 조합으로 평점·리뷰가 많은 맛집·카페·자연 명소 400여 곳을 더했습니다.
  12. 열차 시간표: 국토교통부 열차정보로 7일치 시간표·요금을 받아 교통 탭에 넣고, 네이버·코레일 예매로 연결했습니다.

4. 공공데이터 신청

공공데이터포털은 계정당 인증키가 하나이고, API마다 활용신청을 따로 해야 그 키로 쓸 수 있습니다. 신청하지 않은 API를 부르면 "등록되지 않은 서비스키(코드 30)"가 납니다.

신청 순서

  1. data.go.kr에 로그인합니다.
  2. 검색창에 아래 표의 이름을 입력하고, 유형이 오픈API인 항목을 엽니다. 비슷한 이름의 파일 데이터는 고르지 않습니다.
  3. 활용신청 → 활용목적 "앱 개발(웹·모바일) — ○○ 여행 앱"을 적고 신청합니다.
  4. 마이페이지 → 데이터 활용 → Open API → 활용신청 현황에서 "승인"을 확인합니다. 승인 직후 30분~1시간은 오류가 날 수 있습니다.

한도: 관광공사 API는 개발 계정 기준 하루 호출 수가 정해져 있어(약 1,000회) 한 번에 다 못 받을 수 있습니다. 갱신 코드는 목록이 중간에 끊기면 기존 자료를 지우지 않고 보존하도록 만들어 두었습니다. 한도가 모자라면 포털에서 "운영 계정" 전환(활용사례 등록)을 신청합니다.

날씨는 노르웨이 기상청(MET Norway) 예보를 씁니다. 키가 필요 없고, 앱 이름과 연락처를 User-Agent로 밝히고 출처(CC BY 4.0)를 표시하면 됩니다.

5. 구글·카카오 키

구글 Places API (New)

  1. Google Cloud 콘솔에서 프로젝트를 만들고 결제 계정을 연결합니다.
  2. Places API (New)를 엽니다. "사용" 버튼을 누르고, 이미 켜져 있으면 "관리" 버튼이 보입니다. 이름에 (New)가 붙은 것이어야 합니다.
  3. 사용자 인증 정보에서 API 키를 만듭니다.
  4. 키 제한: 애플리케이션 제한사항 = 없음(GitHub 서버 IP가 매번 바뀜), API 제한사항 = Places API (New)만 체크.
  5. GitHub 비밀값 GOOGLE_PLACES_KEY에 넣습니다.

카카오맵 (코스 지도)

  1. 내 애플리케이션에서 앱을 만듭니다.
  2. 카카오맵 → 사용 설정을 ON으로 바꿉니다.
  3. 앱 설정 → 플랫폼 → Web의 사이트 도메인에 두 주소를 줄을 바꿔 적습니다. 끝에 /를 붙이지 않습니다.
    https://appassets.androidplatform.net (앱)
    https://flyaranaby-collab.github.io (홈페이지)
  4. 앱 키 → JavaScript 키를 tools/app_copy.py의 KAKAO_JS_KEY와 수첩 원본의 KMAP_KEY에 넣습니다. JavaScript 키는 공개용이라 코드에 들어가도 되고, 등록한 도메인에서만 작동합니다.

8. 웹 수첩 고치기

수첩 수정은 Claude에게 말로 부탁하면 됩니다. Claude가 하는 순서는 다음과 같습니다. 직접 할 일은 없지만, 새 대화에서 이어서 작업할 때 이 순서를 알려 주면 빠릅니다.

  1. 저장소의 source/index.html을 고칩니다. 새 문구가 생기면 source/i18n/에 번역을 더하고 build_i18n.py를 실행합니다.
  2. 화면을 휴대폰 크기로 띄워 오류가 없는지 시험합니다.
  3. 웹 수첩(아티팩트)에 같은 파일을 다시 게시합니다. 주소는 그대로 유지됩니다.
  4. python3 tools/app_copy.py source/index.html web/index.html로 앱용 사본을 만들고 저장소에 올립니다. 앱은 다음에 켤 때 자동으로 새 내용을 받습니다.
여러 대화에서 동시에 고칠 때: 다른 대화가 웹 수첩을 먼저 바꿔 두면 게시가 거절됩니다. 이때는 최신 게시본을 기준으로 내 변경을 합쳐야 합니다. 같은 날 두 대화에서 수첩을 고치지 않는 편이 안전합니다.

9. 앱 설치·업데이트

휴대폰에 처음 설치

  1. 휴대폰에서 최신 APK 받기를 누릅니다. 항상 가장 최신 파일로 연결됩니다.
  2. 받은 파일을 열고 "출처를 알 수 없는 앱 설치"를 허용합니다.
  3. 설치 후 앱을 엽니다.

업데이트는 두 종류

  • 수첩 내용(장소·문구·번역·자료): 앱을 켤 때 자동으로 받습니다. 다시 설치할 필요가 없습니다. 안 바뀌면 앱을 최근 앱 화면에서 밀어 완전히 껐다 켭니다.
  • 앱 자체: 새 APK를 위 링크로 다시 받아 기존 앱 위에 설치합니다. 같은 서명 키로 만들어서 덮어쓰기가 됩니다. PC에 연결해 pc/업데이트.bat을 실행해도 됩니다(USB 디버깅 필요, pc/사용법.txt 참고).

10. 홈페이지·검색 등록

  1. 저장소 Settings → Pages에서 Source를 GitHub Actions로 바꿉니다(처음 한 번).
  2. Actions의 "홈페이지 올리기"가 수첩 사본과 장소별 페이지(/place/장소id/), 지역 목록(/region/지역/), sitemap.xml을 만들어 올립니다.
  3. 네이버 서치어드바이저와 구글 서치 콘솔에 홈페이지 주소를 등록하고 소유 확인을 한 뒤, …/sitemap.xml을 제출합니다. 검색에 나오기까지 며칠~몇 주 걸립니다.
  4. 카카오 개발자 사이트의 Web 도메인에 홈페이지 도메인을 추가해야 홈페이지에서도 카카오 지도가 뜹니다.

11. 장소 자료 원칙

이 프로젝트에서 가장 많이 배운 부분입니다. 확인 안 된 장소를 한꺼번에 넣었다가 38곳을 지운 적이 있습니다.

  • 넣기 전에 두 번 확인: 지도 검색으로 위치·영업 여부를 보고, 기사·블로그·관광공사 같은 출처를 하나 이상 확인한 곳만 넣습니다.
  • 모르는 값은 비워 두기: 운영 시간·요금을 확인하지 못하면 지어내지 않고 "방문 전 확인"으로 적습니다.
  • 폐쇄·통제 확인: 산은 산불조심기간 통제(가을 11.15~12.15, 봄), 계곡은 휴식년제, 다리·산책로는 안전등급 통제를 따로 검색합니다.
  • 세 층으로 쌓기: 직접 확인한 큐레이션(가장 정확) → 관광공사(공식, 많음) → 구글 인기 장소(리뷰 기준, 설명은 얇음). 같은 곳이 겹치면 큐레이션 정보가 우선입니다.
  • 사진 우선순위: 운영자 등록 → 위키백과(자유 이용) → 관광공사(공공누리 1유형) → 구글 지도. 사진마다 출처를 표시합니다.
  • 경계 지역: 두 지역에 걸친 산(예: 선자령·노인봉)은 also 칸에 다른 지역을 적어 양쪽에서 보이게 합니다.

12. 다른 지역으로 옮기기

저장소를 통째로 복사한 뒤 아래 항목을 바꾸면 새 지역 수첩이 됩니다. 처음엔 Claude에게 "강원 여행 수첩 저장소를 ○○ 지역용으로 바꿔줘"라고 하고, 이 목록을 함께 보여 주면 빠뜨림이 줄어듭니다.

새로 만들 것

  • 새 GitHub 저장소 (기존 저장소에서 "Use this template" 또는 복사)
  • 새 앱 서명 키와 비밀값 2개 (기존 키를 쓰면 기존 앱 위에 덮어써지니 반드시 새로)
  • 카카오 앱(또는 기존 앱에 도메인 추가), 공공데이터 활용신청은 같은 계정이면 그대로 사용

수첩 원본(source/index.html)에서 바꿀 것

  • REGIONS: 지역 목록(id, 이름, 중심 좌표, 검색어)
  • PLACES, META, LODGING, TRANSIT: 장소·숙소·역 자료
  • KTO_SIGUNGU: 관광공사 시군구 코드 ↔ 지역 대응
  • inGangwon: 지역 좌표 범위(잘못된 좌표 거르기)
  • GH(저장소 이름), SITE_URL(홈페이지 주소), KMAP_KEY(카카오 키)
  • TR_DEFAULT_ST, TR_TO: 열차 역 목록과 지역별 기본 도착역
  • 앱 이름·문구의 "강원" 표현, 계절 행사·특산품·할인 정보

스크립트·설정에서 바꿀 것

  • tools/tourapi_sync.py: areaCode=32(강원)를 새 지역 코드로, 시군구 목록
  • tools/med_sync.py: SIDO 시도 이름
  • tools/gmap_discover.py: CITY 시·군 목록과 바다 여부
  • tools/train_sync.py: HUBS(서울 쪽 출발역), GW(지역 역 이름), 시도 이름 필터
  • tools/app_copy.py: KAKAO_JS_KEY
  • tools/site_build.py, tools/place_pages.js: 지역 링크 목록, 기본 홈페이지 주소, 제목 문구
  • app/build.gradle의 applicationId(예: kr.jeju.travelnote), strings.xml의 앱 이름, 아이콘
  • 워크플로 파일의 비밀값 이름(GANGWON_KEYSTORE 등)과 APK 파일 이름

13. 문제 해결

증상원인해결
작업 로그에 "등록되지 않은 서비스키(30)"그 API 활용신청을 안 했거나 승인 전공공데이터포털에서 활용신청, 승인 후 30분~1시간 뒤 다시 실행
관광공사 장소 수가 갑자기 줄어듦하루 호출 한도 초과로 목록이 끊김지금은 기존 자료를 보존하도록 고쳐 둠. 다음 날 다시 실행
구글 사진·인기 장소가 HTTP 403Places API (New) 꺼짐, 또는 키 제한API 사용 설정, 애플리케이션 제한 "없음", API 제한에 (New) 체크
코스 지도가 약도로만 나옴카카오맵 사용 OFF, 도메인 미등록, 키 불일치지도 아래 설명 글의 이유를 보고 카카오 설정 확인
앱에 새 내용이 안 보임앱이 켜져 있는 동안은 예전 파일 사용앱을 완전히 종료 후 다시 열기
새 APK를 설치하려니 "앱이 설치되지 않았습니다"서명 키가 다름같은 서명 키로 만든 APK인지 확인. 키를 잃었으면 기존 앱 삭제 후 설치
웹 수첩 게시가 거절됨다른 대화가 먼저 새 버전을 올림최신 게시본에 내 변경을 합쳐 다시 게시
저장소에 올리기(push) 거절자동 작업이 그 사이 자료를 올림먼저 받고(pull) 다시 올리기
네이버 예매에 날짜·인원이 안 채워짐네이버가 외부 앱의 날짜·인원 입력을 받지 않음출발·도착역만 자동 입력되는 것이 정상. 날짜·인원은 네이버 화면에서 선택

14. 비용·약관

  • GitHub: 공개 저장소의 Actions·Pages·Releases는 무료입니다.
  • 공공데이터: 무료. 하루 호출 한도만 지키면 됩니다.
  • 구글 지도: 결제 계정이 연결돼 있어 무료 사용량을 넘으면 요금이 나옵니다. 가격 정책이 바뀌기도 하니 결제 화면에서 매달 사용량을 확인하고, 예산 알림을 걸어 두세요. 약관상 평점·리뷰 같은 장소 정보를 오래 저장할 수 없어서 평점은 고를 때만 쓰고, 좌표는 한 달에 두 번 새로 받습니다.
  • 카카오맵: 계정에서 처음 켠 앱 하나에 무료 쿼터가 적용됩니다. 비즈월렛을 연결하지 않으면 요금이 나오지 않고, 한도를 넘으면 지도가 막힙니다.
  • 사진: 위키백과는 작가·라이선스, 관광공사는 "공공누리 제1유형(출처 표시)", 구글은 "사진: Google Maps"를 표시합니다.
  • 열차 예매: 결제·발권은 코레일 또는 제휴사(네이버)에서만 합니다. 앱이 예매를 대신 처리하지 않습니다.
